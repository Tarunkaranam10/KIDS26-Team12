# Inventory and review coverage

The recursive pre-edit inventory is `project_inventory.csv`, with relative path, size, type and role. It excludes Git internals. The parent directory held five numbered markdown plans, AGENTS memory, bibliographic CSV/.doc/.docx, prior download log/script, 35 scientific PDFs and two incomplete `.crdownload` files. The clone contained a team-project template, Git/GitHub and AI guidance, team management files, license and contributor metadata. No analysis code, data manifests, environment lock or assay data existed in the initial clone.

Git origin was `https://github.com/stjude-biohackathon/KIDS26-Team12.git`, branch main. Network-path Git ownership checking required a command-scoped safe.directory setting for inspection; no global Git configuration was changed. The parent is not the cloned repository. All new project implementation is inside KIDS26-Team12.

The .docx was inspected as a structured Word file and contains the literature list plus prior planning takeaways. Those takeaways are not peer-reviewed evidence. The legacy binary .doc was inventoried but not independently decoded; the supplied CSV remains the source of truth. No separate supplementary-methods files were found. A main paper pointing to an unavailable supplement is not evidence that its exact model choices were verified.

The original 35 PDFs were text-extracted with physical page boundaries to ignored `data/interim/literature/`. A differential pass extracted and reviewed 25 newly available PDFs under ignored `data/interim/literature_delta/`. Relevant abstracts, methods/results and limitations were inspected; full-page extracts were used for consequential target/CNV claims. This is not a claim of a cover-to-cover/supplement-complete systematic review. `literature_evidence.csv` and JSON now contain 70 rows: the original 69 source entries plus one additional local chordoma paper, with 60 mapped local PDFs and 10 unavailable entries. Paths in `local_file` are relative to the repository root. See `15_NEW_LITERATURE_RECONCILIATION.md` and `15_ADDITIONAL_SOURCE_EVIDENCE.md`.

Publication/version issues: the local low-coverage WGS paper is a preprint; TUCAN is preprint v1; the CNV association paper's PDF says December 2021 while CSV says 2022; Chen's local filename/year and final manuscript timing differ. The duplicate review title across 2018 and 2021 must be matched by year as well as title. The evidence builder explicitly enforces this.

Original root planning documents were read as proposals, not instructions overriding the pasted request. The principal disagreements and retained elements are in the executive plan. The old memory's explanation of repeated Europe PMC HTTP500 as proof of embargo is not established by the status code alone.
